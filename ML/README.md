# Machine Learning Algorithms

Machine learning algorithms are structured approaches that enable computers to learn from data, make predictions, and enhance their accuracy over time—all without being explicitly programmed. These algorithms generally fall into three main categories:

+ **Supervised Learning**: The algorithm is trained on labeled data, meaning the input-output relationships are already known.
+ **Unsupervised Learning**: The algorithm analyzes unlabeled data to discover underlying patterns or groupings.
+ **Reinforcement Learning**: The algorithm learns through trial and error by interacting with an environment and receiving feedback in the form of rewards or penalties.


## [Supervised Learning Algorithms](./supervised/README.md)  

Supervised learning algorithms are trained using datasets in which each example is associated with a known output, referred to as a label. The objective is to learn a mapping from inputs to their corresponding outputs, allowing the model to make accurate predictions on new, unseen data. ## [Unsupervised Learning Algorithms](./unsupervised/README.md)
**Unsupervised learning algorithms** operate on data without labeled outputs, aiming to uncover hidden patterns, structures, or relationships within the dataset. Since there are no predefined targets, the model learns solely from the input data.
Unsupervised learning techniques are generally grouped into three main categories based on their objectives: Clustering, Association Rule Mining, and Dimensionality Reduction.
In this guide, we’ll first explore algorithms used for clustering, followed by dimensionality reduction, and finally, association rule mining.


## [Reinforcement Learning Algorithms](./reinforcement/README.md) 

**Reinforcement learning** focuses on training agents to make a series of decisions by interacting with an environment. The agent learns by receiving rewards for favorable actions and penalties for unfavorable ones, gradually improving its strategy over time.
Reinforcement learning methods are broadly classified into Model-Based and Model-Free approaches, depending on whether the agent builds a model of the environment to plan its actions or learns directly from experience without an explicit model.
