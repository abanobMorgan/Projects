# Projects

Natural Language Processing (NLP) combines [machine learning](./ML/README.md), linguistics, and artificial intelligence to help computers understand and generate human language.
This roadmap starts by building a foundation in [Machine Learning](./ML/README.md) algorithms, ensuring you understand key concepts like supervised and unsupervised learning, decision trees, SVMs, neural networks, and ensemble methods.

Once the [ML basics](./ML/README.md) are covered, the roadmap progresses into NLP-specific topics, including text preprocessing, embeddings, language models, and modern deep learning techniques for NLP.
Whether you are new to NLP or aiming to strengthen your fundamentals, this roadmap offers a structured path to learn, practice, and apply NLP techniques to real-world tasks like text classification, sentiment analysis, and conversational AI.
